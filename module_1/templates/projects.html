Module 1: Personal Developer Website

For this project, I built a personal website using Python and Flask. The website has three pages: About, Projects, and Contact.

The Python file run.py starts the website. The file pages.py tells Flask which HTML page to show for each web address. I used a blueprint to keep the three page routes together.

Each page has its own HTML template. The templates share a navigation bar from base.html. A CSS file controls the colors, spacing, and layout.

What I practiced

  • Creating a Flask application with Python.
  • Using routes to display different web pages.
  • Writing HTML and using CSS to style a website.
  • Organizing project files and saving changes with Git.
